GitHub 업로드 방법

1. 이 ZIP 압축 해제
2. GitHub 저장소 Wodook22/macro-quant-terminal 이동
3. Add file → Upload files
4. 업로드할 파일:
   - app.py          (핵심 — fredapi 방식으로 교체됨)
   - requirements.txt (fredapi 추가됨)
   - README.md
5. Commit changes
6. Streamlit Cloud 자동 재배포 대기
7. 안 되면: Manage app → Reboot app

Streamlit Cloud Secrets 확인 (필수):
Settings → Secrets에 FRED_API_KEY 있어야 함

절대 업로드 금지:
.env
.streamlit/secrets.toml
