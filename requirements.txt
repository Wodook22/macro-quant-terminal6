# Macro Quant Terminal v15

fredapi 기반 안정적 데이터 로드 버전입니다.

## 핵심 변경 (504 오류 해결)

- FRED CSV 직접 호출 방식 제거 → **fredapi 라이브러리** 사용
- fredapi 없거나 키 없을 때만 CSV fallback (자동)
- 타임아웃 504/404 오류 대부분 해결

## 주요 기능

- fredapi 기반 FRED 데이터 로드
- Beginner/Advanced 보기 모드
- 섹터 PER 밸류에이션 (스코어에 반영)
- 내 포트폴리오 직접 입력 → 추천과 비교 + 리밸런싱 금액
- 거래비용 반영 백테스트 (비용없음 vs 설정 bps 비교)
- 데이터 기준일 + 발표주기별 지연 판정
- LLM 세션당 5회 제한
- 자동 새로고침 (15/30/60분)

## Streamlit Cloud Secrets 설정 (필수)

Settings → Secrets에 입력:

```toml
FRED_API_KEY = "발급받은키"
GEMINI_API_KEY = "발급받은키"
ANTHROPIC_API_KEY = ""
```

FRED 키 무료 발급: https://fred.stlouisfed.org/docs/api/api_key.html

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```
